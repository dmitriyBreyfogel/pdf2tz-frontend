# pdf2tz frontend

Интерфейс сервиса подготовки технического задания на техническое обслуживание медицинского изделия из PDF-инструкции.

## Стек

- React + TypeScript
- Vite
- Нативный адаптивный CSS без UI-библиотек

## Запуск

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173`.

Для production-сборки:

```bash
npm run build
npm run preview
```

## Конфигурация API

Скопируйте `.env.example` в `.env` и задайте адрес backend-сервиса:

```bash
VITE_API_BASE_URL=http://localhost:8080
```

На первом этапе интерфейс реализован как интерактивный дизайн-прототип: загрузка PDF, выбор модели и анимация генерации работают локально. В следующей итерации он будет подключён к общей backend-ручке генерации DOCX, а результатом станут скачиваемый документ и список расходников.

## Ветки

- `main` — стабильная база;
- `dev` — ветка активной разработки.
